Details
Methodology: TDIs = Jira project TDI, issue type Feature, Zone = Communications Services, with an assignee and a target quarter (Fix Version) both set — this matches the GitHub release dashboard's count exactly (52 vs. this dashboard's earlier unfiltered 67) and is applied consistently across every metric here. Discovery allocation = sum of "Allocation in Days" on child Epics (any project) whose title contains "discovery" and whose parent is the TDI. "Refresh from Jira" requires running the local server (python3 server.py) in this folder — opened as a plain file, the button will tell you so instead of silently failing.
